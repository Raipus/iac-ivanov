# iac-ivanov
Репозиторий для работ по дисциплине "Инфраструктура как код"

## Каталоги:
 
1. `work-01` — практическая работа № 1: машина с nginx вручную через веб-консоль и командами Yandex CLI.
2. `work-02` — практическая работа № 2: настройка машин через cloud-init, стенд одним скриптом, балансировщик нагрузки.
3. `hw-01` — домашняя работа № 1: демонстрационный стенд из двух веб-серверов, закрытого сервера приложения, NAT-шлюза и балансировщика. Поднимается и сносится одной командой.

## Как поднять стенд домашней работы (команды выполняются из корня репозитория, нужны Yandex CLI с настроенным профилем, jq и SSH-ключ ~/.ssh/id_ed25519.pub):
 
`./hw-01/create.sh` — поднять стенд
 
`./hw-01/check.sh` — проверить стенд, код 0 означает, что всё в порядке
 
`./hw-01/destroy.sh` — снести стенд
